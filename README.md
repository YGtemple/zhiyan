## 📖 项目简介

**智言（TEDify）** 是一个个人表达训练系统，帮助用户提升路演、面试、会议发言、公开演讲等场景的表达能力。系统通过 AI 反馈 + 进步流设计，把零散的练习变成有记忆、有路线、有正反馈的私人教练式训练旅程。

核心理念：**我知道你想成为什么样的表达者，我记得你上次的问题，也知道我们下一步该练什么。**

## ✨ 核心特性

- **进步流架构** — 不是装饰图表，也不是单一分数趋势，而是完整的教练路径
- **私人教练记忆** — 记住当前训练目标、用户偏好、反复出现的问题、已完成训练任务
- **正反馈机制** — 具体、真实、和训练动作相关的进步反馈
- **六步闭环流程** — 基线 → 第一次口述 → 反馈 → 第二次口述 → 巩固训练 → 下一阶段
- **多场景适配** — 路演、面试、会议、公开演讲
- **能力成长追踪** — 量化进步信号 + 真实变化证据

## 🎯 设计理念

### 什么叫进步？

进步不是单次分数上涨，而是用户朝当前表达目标产生了**稳定、可证据支持的变化**：

- 多次尝试中某些评分维度变好
- 完成了针对性训练任务
- 前后表达片段变得更清楚
- 某个反复问题出现频率下降
- 用户自评更有掌控感
- 表达更贴合目标场景和听众

### 正反馈五步法

1. **命名进步** — 你的开场现在更快进入重点
2. **展示证据** — 给出前后表达片段或评分变化
3. **连接努力** — 这和你练的"直接开场任务"一致
4. **给下一步** — 接下来保留这个开场方式，训练过渡句
5. **保持鼓励** — 但不隐藏不确定性

## 🧠 产品形态：教练路径面板

MVP 形态为一个综合教练路径面板，包含：

- **当前目标和阶段** — 你正在训练什么，现在处于哪个阶段
- **路线阶段** — 基线 → 第一次口述 → 反馈 → 第二次口述 → 下一轮训练
- **量化进步信号** — 各维度评分变化
- **最强证据片段** — 真实表达前后对比
- **已完成任务状态** — 已掌握的训练任务
- **教练记忆** — 系统记住的用户特点和问题
- **下一步推荐** — 接下来该练什么

## 🔄 下一步推荐逻辑

优先级从高到低：

1. **阻塞问题反复出现** → 继续修这个问题，降低任务范围
2. **目标能力改善但不稳定** → 做巩固练习
3. **任务完成且证据稳定** → 进入下一路线阶段
4. **用户场景变化** → 重新映射训练路线
5. **模型置信度低** → 不夸大进步，请用户再做一次尝试

## 👥 用户画像与场景

### 目标用户

- 准备路演/创业比赛的学生和创业者
- 需要提升面试表达能力的求职者
- 需要在会议中清晰发言的职场人
- 想提升公开演讲能力的任何人

### 典型场景

| 场景 | 核心痛点 | 训练重点 |
|------|----------|----------|
| **路演/比赛** | 开场不够抓人、重点不突出 | 直接开场、核心观点前置 |
| **面试** | 回答冗长、逻辑不清 | STAR 结构、简洁表达 |
| **会议发言** | 铺垫太长、没有结论 | 结论先行、结构化表达 |
| **公开演讲** | 紧张、节奏失控 | 控场能力、情绪感染力 |
