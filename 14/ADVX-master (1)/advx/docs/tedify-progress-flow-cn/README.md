## 一句话结论

TEDify V2 的进步流应采用「教练路径面板」。

它不是单独的雷达图、分数趋势图或普通 dashboard，而是一个综合板块，把以下内容放在一起：

- 当前训练目标
- 当前训练路线阶段
- 量化进步信号
- 最关键的表达证据
- 已完成训练任务
- 教练记忆
- 下一步训练建议

## 为什么重要

如果 TEDify 只输出一次报告，它更像一个 AI 诊断工具。

如果 TEDify 能持续记住用户目标、历史问题、完成过的训练、真实进步证据和下一步路径，它才会像一个私人针对性教练。

## 产品核心感受

进步流要持续回答：

> 我知道你想练成什么，我记得你上次发生了什么，我看见你哪里变好了，也知道下一步该练什么。

## MVP 推荐

第一版只做：

- 单个训练目标
- 2 到 3 次训练记录
- 文本分析
- 综合进步面板
- 分数/等级/趋势
- 任务完成状态
- 前后表达片段对比
- 教练总结
- 下一步任务

不要做：

- 多目标并行
- 完整能力树
- 团队 dashboard
- 音频、情绪、停顿、语速、肢体语言分析
- 医学、心理治疗或专业咨询承诺
