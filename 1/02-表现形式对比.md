# 02. 进步流表现形式对比

## 1. 时间线

适合：

- 已完成多轮训练、想回看历史的用户。

展示：

- 每次训练日期
- 口述主题
- 反馈摘要
- 关键变化
- 下一步任务

优点：

- 连续性强，容易让用户看到自己走过一段路。

缺点：

- 新用户内容太少。
- 如果目标不明确，容易变成流水账。

结论：

- 适合作为详情页或折叠历史。
- 不适合做唯一主形态。

## 2. 能力雷达

适合：

- 想快速看多维能力状态的用户。

展示：

- 清晰度
- 结构
- 连贯性
- 说服力
- 场景适配

优点：

- 一眼看到强弱项。

缺点：

- 容易考试化。
- 容易让用户误以为每个维度都能精确测量。

结论：

- 可作为辅助量化视图。
- 不建议作为主形态。

## 3. 训练路线图

适合：

- 需要知道“下一步为什么练这个”的用户。

展示：

- 当前目标
- 当前阶段
- 已完成任务
- 下一步任务
- 解锁条件

优点：

- 最能体现私人教练带路。
- 能驱动下一次训练。

缺点：

- 路径太固定会削弱个人化。

结论：

- 适合作为主骨架。

## 4. 任务链

适合：

- 希望低负担完成训练的用户。

展示：

- 训练任务
- 完成状态
- 任务结果
- 下一任务

优点：

- 行动导向强。

缺点：

- 容易把“完成任务”误当成“能力提升”。

结论：

- 必须绑定效果证据。

## 5. 能力树

适合：

- 长期训练、目标复杂、喜欢体系化成长的人。

优点：

- 长期成长感强。

缺点：

- MVP 阶段数据不足。
- 容易游戏化过度。

结论：

- 长期版可考虑，MVP 不建议。

## 6. 周报 / 阶段报告

适合：

- 每周训练多次、需要阶段复盘的人。

优点：

- 适合留存和阶段性正反馈。

缺点：

- 低频用户会空。

结论：

- 可后置。

## 7. 教练笔记

适合：

- 需要私人感、被理解感的人。

展示：

- 用户目标
- 偏好
- 反复问题
- 教练观察
- 提醒

优点：

- 最能建立“系统记得我”的感觉。

缺点：

- 如果没有证据支撑，会像空泛鼓励。

结论：

- 必须进入综合板块。

## 8. 组合 Dashboard

适合：

- 希望同时看路径、分数、证据、任务的人。

展示：

- 当前目标
- 路线
- 量化趋势
- 证据片段
- 任务状态
- 教练记忆
- 下一步

优点：

- 最符合当前需求。

缺点：

- 信息层级必须克制。

结论：

- 推荐 MVP 采用，但不要做成传统数据看板。
- 具体形态应是“教练路径面板”。
