# zhiyan

口语训练系统的设计集——17 项表达画像、四维评分，以及进步流模型。

## 这是什么

一个口语训练产品背后的设计工作，拆成多份文档而不是塞在一个长文件里。十六个编号文件夹，每个装一个决定。

## 核心想法

大多数口语工具给一个分数。分数不告诉你要改什么，所以这里的设计围绕三件事：

**17 项表达画像**——语速、停顿频率、填充词比例、重音分布、结构清晰度、句长变化等。每项可测，给的是阈值区间，不是通过或不通过。

**四维评分**——结构、连贯、场景适配、语言准确。分开打分，弱的维度才看得见，不会被平均值抹平。

**问题到任务的映射**——每条发现都要产出一个任务。「开场语速快了 15%」变成「重录前 30 秒，每句控制在一口气之内」。

## 进步流模型

想得最久的一块：当指标和任务是两回事时，怎么表示「进步」。

```
基线录音 → 证据 → 诊断 → 任务 → 重录 → 对比
```

对比只有在任务和重录使用同一场景时才算数。否则数字会动，但和练的东西无关。
