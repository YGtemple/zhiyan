## 结论

TEDify V2 的第一步信息获取，不应该被设计成普通注册表单，而应该是训练系统的「路由层」。

它的作用是决定：

- 用户要练什么表达场景
- 用户处于什么准备阶段
- 用户面对谁说
- 用户什么时候要用
- 用户要讲多久
- 用户最想先改善什么
- 后续基线测试怎么出题
- 后续评分维度怎么加权
- 后续训练任务怎么分配
- 后续反馈语气和密度怎么调整

## 推荐首屏

首屏只问 5 个必问问题，加 1 个可选问题。

必问：

1. 你这次主要想练哪类表达？
2. 你现在准备到哪一步了？
3. 这次主要讲给谁听？
4. 这次表达什么时候要用？
5. 这次大概需要讲多久？

可选：

6. 你最想先改善哪一项？最多选 2 个。

这样可以完成第一轮训练路由，同时避免用户一进来就被长问卷劝退。

## 当前能力边界

TEDify 当前只分析口述转写文本。

不能声称已经支持：

- 真实音色分析
- 真实停顿分析
- 真实语速分析
- 真实情绪分析
- 肢体语言分析
- 眼神分析

这些可以作为用户自述痛点或未来能力入口，但不能作为当前已检测指标。
